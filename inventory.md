# RepoMind Inventory

Audit date: 2026-07-02

## Source Folders

- `backend/`: FastAPI API, configuration, Git clone utility, repository parser, scanners, analysis layer, indexer, and report generator.
- `frontend/`: Next.js app, Tailwind CSS, UI primitives, and package metadata.
- `tests/`: pytest coverage for config, parser, security, dependency analysis, and orchestration.
- `docs/`: architecture, engineering, and audit reports.

## Backend Modules

- `backend/api/main.py`: HTTP API for `/health` and `/scan`.
- `backend/config.py`: `.env` and environment-backed settings.
- `backend/utils/git.py`: GitHub URL validation and shallow clone.
- `backend/parsers/repository.py`: bounded text parser with ignored directory handling and UTF-8 BOM stripping.
- `backend/scanners/security.py`: rule scanner for secret-like assignments, `eval`, disabled TLS verification, shell execution, TODO, and FIXME.
- `backend/scanners/dependencies.py`: manifest parser for `requirements.txt`, `package.json`, and `pyproject.toml` notes.
- `backend/agents/analyzer.py`: deterministic business, architecture, quality, requirement, and recommendation summaries.
- `backend/agents/graph.py`: optional LangGraph wrapper with direct fallback.
- `backend/agents/llm.py`: optional LiteLLM/OpenRouter wrapper.
- `backend/rag/indexer.py`: Chroma index writer with JSON fallback.
- `backend/reports/generator.py`: Markdown report renderer.

## Frontend Modules

- `frontend/app/page.tsx`: repository scan form, loading/error/success/empty states, report rendering, and timing display.
- `frontend/app/layout.tsx`: root layout and metadata.
- `frontend/app/globals.css`: Tailwind globals and design tokens.
- `frontend/components/button.tsx`: accessible button primitive.
- `frontend/components/input.tsx`: accessible input primitive.
- `frontend/lib/utils.ts`: class name merge helper.

## Environment Variables

Runtime configuration is stored in `.env`.

- `OPENROUTER_API_KEY`: OpenRouter provider key.
- `MODEL_NAME`: LiteLLM model name, defaulting to `openrouter/google/gemini-2.5-flash`.
- `EMBED_MODEL`: embedding model setting for future embedding work.
- `MAX_FILES`, `MAX_FILE_SIZE`, `SCAN_DEPTH`: parser limits.
- `CHUNK_SIZE`, `CHUNK_OVERLAP`: local index chunk settings.
- `REPORT_DIR`, `CACHE_DIR`, `VECTOR_DIR`, `VECTOR_COLLECTION`: runtime storage settings.
- `CORS_ORIGINS`: comma-separated backend CORS origins.
- `FRONTEND_PORT`, `BACKEND_PORT`: local server ports.
- `DEBUG`: development behavior flag.
- `NEXT_PUBLIC_BACKEND_URL`: frontend API base URL.
