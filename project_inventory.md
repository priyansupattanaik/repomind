# Project Inventory

Audit date: 2026-07-02

## Source Structure

- `backend/`: FastAPI API, scan orchestration, repository parsing, scanners, local indexing, report generation, and Git utilities.
- `frontend/`: Next.js dashboard, Tailwind styling, UI primitives, and frontend package metadata.
- `tests/`: focused pytest coverage for config, parser, security scanner, dependency scanner, and local orchestration.
- `docs/`: architecture and previous engineering report.
- `.env`: local environment file for runtime configuration.
- `README.md`: setup, run, scan, and report documentation.
- `requirements.txt`: backend Python dependencies.

## Backend Modules

- `backend/api/main.py`: exposes `GET /health` and `POST /scan`.
- `backend/config.py`: loads `.env` and environment-backed settings.
- `backend/utils/git.py`: validates GitHub URLs and shallow-clones repositories.
- `backend/parsers/repository.py`: scans text files within max file, size, and depth limits.
- `backend/scanners/security.py`: rule-based scanner for secrets, `eval`, disabled TLS checks, shell execution, and TODO/FIXME.
- `backend/scanners/dependencies.py`: parses `requirements.txt`, `package.json`, and notes `pyproject.toml`.
- `backend/agents/analyzer.py`: deterministic business, architecture, quality, gap, and recommendation summaries.
- `backend/agents/graph.py`: optional LangGraph wrapper with direct fallback.
- `backend/agents/llm.py`: optional LiteLLM wrapper.
- `backend/rag/indexer.py`: Chroma indexing when installed, JSON fallback otherwise.
- `backend/reports/generator.py`: Markdown report rendering.

## Frontend Modules

- `frontend/app/page.tsx`: scan form and report rendering.
- `frontend/app/layout.tsx`: root layout metadata.
- `frontend/app/globals.css`: Tailwind globals and CSS variables.
- `frontend/components/button.tsx`: shared button primitive.
- `frontend/components/input.tsx`: shared input primitive.
- `frontend/lib/utils.ts`: class name merge helper.
